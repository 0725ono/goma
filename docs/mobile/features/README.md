# 📱 Mobile 機能設計 (features)

個々の機能ごとの設計ドキュメントを置く。1 機能 = 1 ファイル（または 1 サブフォルダ）を基本とする。

全体に効く横断的な方針（アーキテクチャ・状態管理・認証など）は
[../architecture/](../architecture/) にあり、ここには**その方針に沿った個別機能の設計**を書く。

## 命名の目安

- `calendar.md` — カレンダー表示（月間 / 週間・バーチカル / ガント）
- `spaces.md` — スペース（個人 / 家族）の切り替え
- `notifications.md` — 予定・タスクの通知

> まだ機能設計ドキュメントは無い。第一段階（[../architecture/frontend-architecture.md](../architecture/frontend-architecture.md) の「第一段階スコープ」）の完了後、機能ごとにここへ追加していく。

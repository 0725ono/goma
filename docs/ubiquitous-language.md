# 📖 ユビキタス言語（ドメイン用語集）

このプロジェクトの会話・コード・ドキュメントで使う用語の正を定める。
概念 ↔ 英語名（コード上の識別子）↔ 日本語名の対応表であり、コードの写しではない。

## 運用ルール

- **識別子（クラス名・テーブル名・エラーコード等）は英語名を使う。英語名の正はこの表**。
- **コードとこの表が食い違ったら、それはバグ**。どちらかを直す PR を立てる。放置しない。
- 新しいドメイン概念を導入するときは、実装より先にこの表へ行を足す。
- 「使わない別名」に挙がった語は、会話・コメント・ドキュメントでも使わない。
  表記揺れは「間違った言葉」ではなく「正しい言葉が複数あること」から生まれるため、
  捨てた候補を明記することが再発防止になる。

## 用語

| 用語（正） | 英語 / 識別子 | 意味 | 使わない別名 |
|---|---|---|---|
| スペース | Space / `space` | 予定・タスクが属する空間。個人用と共有用（家族）がある。1ユーザーは複数のスペースに所属できる | 空間、グループ、ワークスペース |
| 予定 | Event / `event` | 時間枠（開始日時〜終了日時）を押さえるもの。バーチカルカレンダーにブロックとして描画される | イベント、スケジュール、アポ |
| タスク | Task / `task` | 期限（締切日時）と完了状態を持つもの。カレンダー上にピンポイントの期日として描画される | TODO、やること |
| ユーザー | User / `user` | アプリを使う人。認証は Firebase が担い、Firebase UID で PostgreSQL 側のプロフィールと連結する | メンバー、アカウント |
| 所属 | SpaceMember / `space_member` | どのユーザーがどのスペースに属しているかの関係（多対多） | 参加、メンバーシップ |

## エラーコードとの関係

エラーコードの命名は `<対象>_<事象>`（例: `EVENT_TIME_INVALID`）とし、
**対象にはこの表の英語名を使う**。カタログと命名規則の詳細は
[api/architecture/error-contract.md](./api/architecture/error-contract.md) を参照。
